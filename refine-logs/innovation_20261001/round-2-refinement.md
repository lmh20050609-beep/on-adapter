# iAdapter：从文本增量价值出发的修订与创新

日期：2026-10-01。这是已见部分结果后的探索性方案，不是预注册的独立确认。现有 N3 扩域矩阵继续使用 ef22b671 锁定源码；本方案先保存到 Windows，避免改变运行中队列。

## 问题锚点

- 根本问题：在数值骨干冻结、文本异步到达、多步标签延迟的条件下，用小成本在线适配提升真实预测质量。
- 必须解决的瓶颈：文本及在线更新的作用随数据域和预测长度变化；当前把梯度、文本和专家一起送进门控，不能直接判断文本分支的增量收益，复杂组件的必要性证据也不足。
- 非目标：本轮不预训练大模型，不把近期论文模块全部拼接进 iAdapter，不用未来信息判定当前文本是否可信，不把新结果当作旧投稿表格的来源恢复。
- 约束：仅本机 RTX 4060 Laptop 8GB；复用现有数据、冻结 BERT、Qwen2.5-0.5B 与原点级回放；原始目标缺失掩码保留；end_date 只是可用时间代理；正式矩阵与新探索分别记录。
- 成功条件：哪怕平均改善低于 1%，只要完整保留跨 seed 配对结果、退化域、成本和适用范围，便视为有价值进展；若能同时说明何时使用文本、何时应减弱文本，则形成更强的方法论。统计显著性和普遍优越性需要各自证据。

## 一、第一性原理推导

预测原点 t 的允许信息为 F_t：数值历史、截至 t 可用的文本、在 t 前已消费的反馈。所有输出必须是 F_t 的函数。

平方误差下，理想数值预测为 E[Y|X]，理想多模态预测为 E[Y|X,T]。在同一总体、有限二阶矩和精确条件期望下，两者的风险差为 E[||E[Y|X,T]-E[Y|X]||²]≥0。这个恒等式只说明“额外信息的理想价值”，不保证有限样本模型加入文本就会变好。

因此文本真正应该帮助的是数值预测尚未解释的部分。设同原点发出的数值预测为 n，文本辅助预测为 m，分支差异 d=m-n，数值残差 r=Y-n。混合预测 n+αd 的误差变化是：

    (r-αd)²-r² = -2αrd+α²d²。

决定文本分支力度的量是残差与分支差异的对齐 rd，以及差异幅度 d²。LLM 自报置信度、文本新近程度、梯度大小都不是这两个量的替代品。这里 d 是两条预测路径的差异，不能直接解释为文本的因果效应。

若过去成熟样本提供 A=Σw rd、B=Σw d²，则带先验收缩的经验平方误差最优系数为：

    α = clip((A+λ α₀)/(B+λ), 0, 1)。

这是标准受约束最小二乘的直接结果，不宣称公式本身创新，也不保证非平稳未来风险下降。它为更复杂的 iAdapter 门控提供一个必须超越的可解释对照。

## 二、当前证据如何约束路线

- E003：五维 LLM 表示相对同维原始 BERT PCA 表示，Energy 与 SocialGood 在线 MSE 平均分别改善约 3.14% 与 1.54%；仍不胜过两个域各自的最强参考。
- N1：同字符集合的近期文本前置，SocialGood 在线 MSE 有小幅平均改善，Energy 三个 seed 都退化。这支持研究文本使用条件，不能推出“近期文本更好”。
- N3 已完成 50 次评估并通过原目标/掩码审计：Health 上 LLM5 在线相对 numeric-online 的平均 MSE 改善 7.99%（3/5 seed），相对 raw5-online 改善 6.06%（4/5），但相对 LLM5-static 退化 8.13%（0/5 改善）；Agriculture 相对 numeric-online 退化 4.71%。这要求文本价值与在线更新价值分开建模。Health 的五组重复日历记录已披露，H=6 表示六个报告记录。
- 反馈因子实验：参数在线更新与梯度缓存刷新必须分开解释；刷新反馈没有显示稳定额外收益。
- 审稿人要求的是收益边界、公平比较、组件必要性、文本/路由机制和成本。添加新模块不能代替这些证据。

以上均是已有探索的锚点，新方案不再把这些域称为未见测试集。N3 已锁定 Agriculture/Health 扩域，保持原输入与原候选，不因本方案改动。

## 三、主路线 A：按成熟反馈校准文本分支力度

### 方法命题

复用已有数值和文本辅助分支，以原点发出的预测计算增量风险；让低维在线校准器决定每个 horizon 的文本使用力度。主要贡献候选是“异步外生文本路径的互补性如何随 horizon 和反馈历史变化”的实证发现，以及低维机制能否替代复杂路由。公式、在线组合和原点成熟协议均已有先例；不将新命名的线性集成作为独创算法。

### 最小实现

1. 数值路径使用现有 numeric-only 适配器；文本路径先使用 E003 的 LLM5 简单融合。共享同一冻结骨干、训练边界、原点和目标掩码，两条适配器独立预热，不共享在线优化状态。
2. 在原点 t，先用校准状态 α_{t,h} 产生 n_{t,h}+α_{t,h}(m_{t,h}-n_{t,h})，再处理此刻成熟的反馈。保存原点 ID、分支原预测、α、目标索引与文本 ID，不用回放后的新预测评估分支价值。
3. 主 pilot 使用既有 benchmark 回放的全窗口成熟假设：origin+H 行可用后才消费该原点全部有效目标。它是记录索引可用性模型，不宣称真实标签 publication-time 已核验。两条适配器继续独立按同一全窗口协议更新，校准系数不缩放它们的梯度。
4. 逐 h 变体暂不执行：需要 availability_time(origin,h,channel,target_version) 的真实来源，不能用 origin+h 自动构造真实发布时间。取得依据后，逐 h 校准器和全窗口校准器使用各自合法成熟集合，分支更新仍一致；该变体单列，也不宣称部分真值反馈本身创新。
5. 更新采用标准化目标单位。对每个 h，a_h=Σ_c valid·(Y-n)·(m-n)，b_h=Σ_c valid·(m-n)²，按有效 cell 的原损失归约，不在另一路改按 origin 平均。每个当前记录索引 t 的预测保存后，统一对所有 A/B 衰减 ρ^(t-last_t) 一次，再按排序稳定的成熟集合累加；多个标签同一时刻到达不产生额外衰减。无文本原点输出 n，其成熟事件不加入文本价值累计量；仍保留统一时间衰减。原点/lead/channel/目标版本各只消费一次，缺失 cell 不加入。λ_h 收缩到校准先验 α₀,h；B 近零或无有效校准样本退回 α₀,h。
6. 第一版只使用 H 个系数和 2H 个累计量，不增加门控网络，不改变五专家模型。完整 iAdapter 保留为独立参考；若它不能胜过这个简单校准器，正文明确承认。

### 训练与选择

正式 A pilot 采用 60/10/5/5/20 的时间划分：0–60% 拟合骨干/适配器/PCA/标准化；60–70% 只选择骨干 checkpoint；70–75% 是标签未参与参数形成的校准片段；75–80% 选择组合器规则；80–100% 评估。Energy/SocialGood 已有骨干的 checkpoint 选择边界为 70%，可复用；Agriculture/Health 的 N3 骨干曾用完整 60–80% 选择，不能用于这套干净校准流程，扩域时需重选 checkpoint。

校准片段上两条分支冻结在训练预热权重，真实发出 n/m；只使用在该片段末前已全窗口成熟、有文本且有效的目标估计 α₀,h 和 mean(d²)_h。α₀,h=clip(A_cal/B_cal,0,1)，无样本回到 0.5。固定归一化/PCA 仍只拟合最初 60%。验证使用这些先验并复制分支权重，允许按照所比较的分支更新规则进行在线回放；其系数、优化器、分支状态和队列全部丢弃。

评估重新载入训练预热权重，A/B 清零，清空反馈/优化器/队列，仅通过 α₀,h、λ_h 注入校准先验；不把校准 A/B 和同批伪样本先验重复计入。校准片段最后尚未成熟的记录不带入评估。原数据多个时段已经被研究者查看，这仍是探索性重划分，不冒充独立未见确认。后续未见时间段确认需另取得新数据。

候选超参数至多四组：ρ∈{1,0.98}，κ∈{1,10}，λ_h=κ·校准片段有效 cell 的 mean(d²)_h+1e-8。验证以每个数据域相对同一数值分支的 MSE 比值平均，再在所有 seed 平均，选择唯一一组；平局按较小复杂度/ρ=1 的固定顺序处理。所有评估锁定这一选择，不为每个测试域挑最好配置。没有合法校准发出日志时先补日志，不以测试记录估计先验。

### 必须比较的已知方法

在同一发出预测账本上比较数值路径、文本路径、校准确定的固定 α_h、等权、delayed endpoint Hedge、预定义 α∈{0,0.25,0.5,0.75,1} 的 mixed-candidate delayed Hedge，以及所提最小二乘。Hedge 使用相同成熟集合/horizon 粒度，正先验下界 1e-6，学习率候选四组 η∈{0.01,0.1,1,10}，预算与 LS 相同，不引用未满足的有界损失 regret 保证。混合候选 Hedge 防止仅靠两个端点对照制造 LS 的优势。

名字拆开：branch-static 表示分支参数冻结；branch-online 表示分支按成熟队列更新；gate-fixed 表示系数固定；gate-adaptive 表示系数变化。gate-fixed+branch-online 不能称 static system。Health 的 LLM5-static 强结果始终保留。共享一个 α 与 H 个 α 作为同日志轻量对照，不另训练神经网络。

已有发出预测可先做纯诊断和相同初值的冷启动回放，标为“后见结果的算法诊断”；它缺合法训练校准先验，不能替代上述正式 pilot，也不进行测试超参数选择。

### 三个验证块

1. **增量价值**：Energy/SocialGood 上已有原预测的时间回放；随后对新固定切分继续探索；仅新增且未参与设计的时间段用于独立确认。报告绝对和相对 MSE/MAE、逐 seed 差值、胜负数与退化，不设置 2% 的淘汰线。
2. **机制区别**：固定 α、端点 Hedge、混合候选 Hedge、LS；共享 α 与 per-horizon α。全窗口成熟为当前可执行规则，逐 h 留待真实标签时间证据。画 α、成熟标签数量、分支差异与原预测误差；后验 oracle 仅作可达到空间诊断。若收益只回到 numeric 水平且 α≈0，则结论是抑制弱路径，不是利用了语义。
3. **文本必要性与简化**：LLM5 vs同维原文本；同一文本路径换成预算匹配、仅来自当前前已可用训练库的历史错配/空文本，不随机全测试洗牌。报告 numeric、text 与混合各自误差，避免把参数估计差异当文本因果。成本包含双路径预测/更新、共同冻结前缀、冻结编码、两套 replay 缓存和校准账本。α=0 也通常仍需事先计算 m，不能宣称关闭权重就节省了文本推理。

### 已知失败模式

- d 的方差很小：系数估计不稳定，采用先验收缩并报告 d²。
- 严重概念变化后反馈滞后：校准会慢，逐 h 更新只能减少部分等待，无法凭空知道未来。
- 两个路径不匹配或训练状态污染：停止计入结果，修复原点/掩码/状态匹配。
- α 接近零：说明当前历史证据下文本路径权重很小，还须结合成熟样本量与内容对照辨别原因；不通过改测试规则强迫使用文本。
- 没有足够信息增益：保留简单 numeric-only 路径，不把“能关文本”本身当作成功创新。



所有阶段按目标终点和成熟时间截断，而非仅筛 origin：用于拟合、checkpoint 选择、校准或规则选择的所有目标必须在该阶段截止边界前已可用；跨界未成熟窗口不消费。历史 lookback 可跨左边界。Energy/SocialGood 现有骨干复用前必须核验选择目标也未越过 70%，不能只看 origin 范围。评估只使用完整 H 步目标落在评估区域的公共原点，末尾不补算。

Hedge 的每个 η 候选都从同一合法校准账本，用冻结 n/m 和同一成熟集合回放取得正初始权重，随后复制到验证与评估；不携带验证权重。endpoint 和五个固定混合候选按每个 h 的有效 cell 的 squared-error sum 更新，与 LS 的统计单位一致。1e-6 floor 在初始化及每次归一化后都施加，随后再次归一化；全缺失和无文本不提供损失证据，已选规则保持一致。

Health 的旧 N3 静态优势保留为历史参考。未来新分割/新 checkpoint 的 static/online 必须重新生成匹配对照，不把旧 N3 数字拼入新 A 主表计算提升。B_cal,h≤1e-8（包括有样本但分支一致）时 α₀,h=0.5。
