# A：成熟反馈下的文本路径校准实施计划

2026-10-01。沿用已审核的第一性原理 FINAL_PROPOSAL；本轮是已见数据之后的探索性实施，不声称独立确认。原 N1/N3 和原 190 次结果保持独立。

## 锁定范围

Energy、SocialGood，H=6，seed=2023/2024/2025。只复用已选骨干和训练预热权重，不新增神经模块、不搜索 LLM prompt/model。RTX4060 Laptop，现有 WSL llm 环境，串行执行。

切分：0–60% 训练；60–70% 原骨干 checkpoint 选择；70–75% 校准；75–80% 组合器规则选择；80–100% 评估。全部窗口目标终点必须在各阶段截止边界前；lookback 可跨左边界。逐 h 标签发布未取得依据，不执行逐 h 更新；全 H 成熟仍是记录索引的 benchmark 可用性假设。

## 固定分支与比较

数值适配器、LLM5 简单融合、raw-BERT-PCA5 简单融合各自复用训练预热权重，共享同一冻结 OT 骨干。训练统计/PCA/LLM 标签标准化均复用最初60%拟合值。先补后20%的固定文本输入，不使用目标。现有 cache 只覆盖80%，原 cache 不修改。

校准：numeric-static/raw5-static/LLM5-static。

选择/评估：每个分支都保存 static/online；完整版 iAdapter-online 仅在评估片段作独立参考，使用它自己的原训练预热权重。所有对照使用相同原点与原目标掩码。每个片段从训练预热重新开始；验证在线状态不带到评估。

组合场景预先固定三种：numeric-online+text-online（主要）；numeric-online+text-static；numeric-static+text-static。LLM5 与 raw5 都运行。支持的当前文本错配/空文本只是同一在线状态下的诊断，不作为完整替代训练政策，不能证明文本因果。

## 校准与规则选择

固定 alpha、等权、端点 delayed Hedge、五个固定混合候选 delayed Hedge、per-horizon LS、shared LS。LS候选四组 rho∈{1,.98}、kappa∈{1,10}；Hedge候选四组eta∈{.01,.1,1,10}。Hedge每个eta都用同一校准账本 warm start；LS只以alpha0和lambda注入先验，评估A/B=0。

每个算法族只选一个全局设置。验证得分为各域/seed/表示/预先固定场景相对同一数值分支MSE的比值平均；不选择测试最优路径。原数据已被查看，明确这是一种探索性规则选择。无文本输出numeric且不加入价值更新；时间衰减按每个当前记录索引一次。原点全窗口成熟时使用原发出的 n/m 和真实有效标签；末尾不flush未成熟记录。

## 执行顺序与验收

1. 核验骨干配置、拟合/选择窗口目标边界、旧预热来源和数据/变换身份。
2. 测试纯组合器：预测先于消费、未来目标不改变当前预测、缺失不影响状态、同刻消费稳定、convex范围、旧状态不带入新片段、指标可重算。
3. 新代码审查；提交源码；固定文本表示prepare/generate。
4. Energy/2023 完整账本sanity。通过后运行其余五组。不得重启正在运行的句柄，不覆盖失败组。
5. 仅在全部验证账本齐全后选参数并锁定。然后全部评估，不按测试分数调参。
6. 汇总全部seed/失败/退化、生成alpha与预测轨迹、测量校准器增量与双分支成本。参数规模报告总和，静态/在线成本分开。

## 成功条件与边界

低于1%或有波动的改善也计为进展；无最低2%淘汰线。能否形成贡献由文本内容/在线分支/一般集成三者的分离证据决定。没有收益时保留结果，不追加模块或大范围调参。旧Health/N3数字不拼入本表。真publication-time、完整VoT先验及原投稿来源恢复仍是独立未完成任务。

固定语言模型新输入生成最多600秒，编码批1，OOM只缩编码批/串行，模型/horizon/seed不变。其余耗时先由sanity测量后估算，不承诺固定天数。
