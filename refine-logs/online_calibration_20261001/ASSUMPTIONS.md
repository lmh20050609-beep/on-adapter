# 实现前决策账本

2026-10-01。以下在依赖实现前确定。

| 决策 | 采用值与理由 |
|---|---|
| 额外seed | 本最小pilot沿用E003的三个seed；五seed扩展是后续确认，不伪称已完成 |
| 组合场景 | 三个预定场景，全报告；不在评估段挑最好分支政策 |
| 全局选参单位 | 同一算法族在两个域、三个seed、两个表示、三个场景的验证MSE比值均值，所有场景等权 |
| 共享alpha | 汇总全部h/channel的A/B；lambda由相同校准cell单位求mean(d²)；一个系数广播到H |
| 近零 | epsilon=1e-8；Bcal≤epsilon时alpha0=.5；lambda=kappa·mean(d²)+epsilon |
| Hedge floor | 初始和每次更新后clip权重下界1e-6再归一化；校准账本warm start，验证权重丢弃 |
| 零文本 | 组合直接输出numeric；成熟记录消费但不添加价值统计；LS仍按当前记录索引遗忘 |
| 部分标签 | 暂不执行；不能把origin+h代替真实标签发布时间 |
| 标签版本 | 使用本地原CSV固定版本与缺失掩码；同一原目标出现在不同预测origin时是不同任务，不当独立统计样本 |
| 后20%文本 | 固定旧64token可见规则和Qwen prompt/greedy/标签；复用旧cache，只补缺key；不读未来标签 |
| 冷启动 | 每个片段的分支反馈/优化器/队列归零；训练预热权重复用；主分数包括开头无成熟标签阶段 |
| 校准截止 | 冻结分支校准账本仅发出目标完整落在校准段的预测；先验可使用截至calibration_end−1已成熟的这些记录。Hedge用同一集合按成熟顺序初始化，不把验证/评估末尾未消费记录flush，也不延长任何阶段边界 |
| 内容诊断 | 历史训练donor和同状态zero-text；原文本在线更新不变，明确是当前内容敏感性，不是替代运行政策 |
| 强完整版 | 评估片段另跑原full在线，使用原同骨干预热；不与旧不同原点的full分数相比较 |
| 成本 | 分支实测分别保存；双分支总成本包含两条路径，不能把alpha=0当节省；共享前缀优化未实现就不声称 |
| 环境 | 复用已完成N1/N3/VoT的WSL llm；不安装新框架，不停止用户其他进程 |
