# iAdapter：当前可交付的 review 修订结论

本轮已把“能否稳定获益、组件是否必要、在线成本多少”变成可追溯的实验与回复材料。**结果支持收紧论文主张，不支持继续写普遍优越、所有组件必要或已证实语义分工。** 完整论文未整合或提交；本目录交付正文替换段落、回复草稿与证据索引。

## 最值得写入回复的发现

| 审稿疑问 | 已获得的证据 | 建议处置 |
|---|---|---|
| 收益是否一致 | 原190矩阵的H6主表：完整模型MSE最低2/5域、MAE最低1/5；文本加法相对数值MSE改善0/5域 | 删除 consistently/significantly，完整保留负结果与配对差值 |
| 新外部比较是否支持优越性 | 五域五seed，75静态+75在线；iAdapter在线对数值在线仅Security/Climate平均MSE略好，五域MAE均更差 | 定位为受限系统评估，不恢复旧Table2 |
| 是否只是在线更新起作用 | iAdapter在线较自身静态三域均值改善、两域退化 | 仅描述参数更新与反馈刷新的共同效果，不归因于单个模块 |
| GPT4MTS是否被击败 | 固定GPT在线扩展25/25单元两指标均比自身静态更差；iAdapter对静态GPT仅1/5域平均MSE较低 | 同时展示强静态基线，不能靠退化扩展建立优越性 |
| 复杂组件是否必要 | 三seed因子实验；五seed去正则/单MLP含新增Energy反例；原关键输入消融 | 降低必要性主张，不按观察到的最佳结果换默认模型 |
| 当前文本内容是否有效 | 80个同状态诊断序列未显示稳定内容优势；旧H6路由22/25高度集中 | 停止C2/C3，撤回语义专家分工解释；不推断原始文本无信息 |
| 是否轻量 | 完整投影+适配器约为小骨干6倍参数；实测预测/更新/编码成本 | 明确比较对象，改为具体参数和毫秒，不泛称开销可忽略 |
| 压缩能否保精度 | E路线无候选同时通过两域预定精度/参数门槛 | 结束该分支，不追加宽度搜索或放宽门槛 |

共同OT在线表中，iAdapter相对数值在线的平均MSE变化为：Economy +14.10%、Energy +42.85%、Security −0.095%、SocialGood +1.65%、Climate −0.242%。这些是均值之比，不是逐seed百分比均值。五域平均MAE都更高。将六个静态/在线系统并列时，iAdapter在线在五域均不是最低平均MSE或MAE；这不是等文本预算的机制消融。

当前51项协议/审计/回归测试通过。原190单元已有原CSV核验；在线25组记录核验通过。独立审查又读取全部75在线和75静态预测，从原CSV重建OT目标与掩码，重算指标及配对汇总，未发现数值差异。静态与在线的前7个预测在更新生效前一致。详细范围见 [验收记录](COMPLETION_AUDIT.md)。
